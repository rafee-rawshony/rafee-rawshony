### 🔹 What I Focus On

- **Full-Stack Web Engineering** → Building fast, SEO-friendly applications with **Next.js (App Router)**, **React**, **TypeScript**, and **Tailwind CSS**.
- **Backend & Database Architecture** → Designing clean schemas and REST APIs using **Node.js**, **PostgreSQL**, **Prisma ORM**, **Supabase**, **Laravel**, and **Django**.
- **Security & Cloud Storage** → Implementing custom **JWT Authentication (`jose`, `bcryptjs`)**, role-based access control (RBAC), and **Cloudflare R2** object storage.
- **DevOps & Infrastructure** → Managing self-hosted Linux **VPS deployments (Coolify, Docker)**, **Cloudflare DNS**, and optimized local workflows with **`pnpm`**.
- **AI & Browser Automation** → Integrating LLM workflows (**Gemini, OpenAI, Claude**) and building custom **Chrome Side-Panel Extensions**.
